Controls how aggressively older messages are compressed into summaries. Lower values = more aggressive (less context kept). Higher values = more context but higher token cost.

Embedder Provider

The embedder powers semantic file search (find_relevant_files). Choose how it runs — locally in your browser (Transformers.js) or via an OpenAI-compatible API endpoint. The embedder's credentials are independent from the chat LLM, so you can point them at different hosts.
Local mode runs the model in your browser — no API calls, no key required, but loads ~25–130MB on first use. Remote providers expect POST /embeddings in OpenAI shape.
Base URL — /embeddings is appended automatically.

MCP Servers

            
Connect Model Context Protocol servers (HTTP transports only — stdio is unavailable in the browser). Each server's tools enter the Catalog under mcp.<serverId> and reach the model via find_tool discovery + sticky admission. Adding a server costs ~0 baseline tokens.
